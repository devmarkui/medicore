🎯 HOW TO ADD A NEW SERVICE CATEGORY
═════════════════════════════════════════════════════════════

1. Login to the system
2. Go to: Settings → Services Management
3. Under "Service Categories" tab, fill the form:
   • Category Name: "Emergency Services"
   • Icon Class: "icon-alert"
   • Description: "24/7 emergency care"
4. Click "Add Category"
5. ✅ New tab appears on Reception Desk!

═════════════════════════════════════════════════════════════

🎯 HOW TO ADD A NEW SERVICE ITEM
═════════════════════════════════════════════════════════════

1. Login to the system
2. Go to: Settings → Services Management
3. Under "Service Items" tab, fill the form:
   • Item Code: "EMRG001"
   • Item Name: "Emergency Consultation"
   • Category: "Emergency Services" (select from dropdown)
   • Price: "2000"
   • Description: "Urgent medical consultation"
4. Click "Add Item"
5. ✅ Item appears on Reception Desk under "Emergency Services" tab!

💡 WORKFLOW FOR RECEPTIONIST
═════════════════════════════════════════════════════════════

PATIENT VISITS RECEPTION:

1. Receptionist opens: /appointments/reception-desk

2. Enter patient phone number
   → System searches for existing patient
   → If found: Auto-fills details
   → If new: Fields ready for manual entry

3. Browse service tabs or use search
   → Click "All Services" to see everything
   → Or click specific category tab

4. Click service items to add to bill
   → "General Consultation" clicked
   → Item appears in Bill Summary

5. Adjust quantities if needed
   → Use +/- buttons
   → Bill totals update instantly

6. Apply discount if applicable
   → Enter discount amount
   → Grand total recalculates

7. Select payment method
   → Cash or Card

8. Click "Confirm"
   → Bill finalized
   → Ready for next patient

🛠️ TECHNICAL DETAILS
═════════════════════════════════════════════════════════════

DATABASE:
  Engine: MariaDB 11.4
  Tables: service_categories, service_items
  Records: 6 categories + 15 items (pre-seeded)

BACKEND:
  Framework: Flask (Python)
  Routes: 12 total (7 settings + 4 API + 1 main)
  Security: CSRF tokens, parameterized queries
  Database: MySQL connector with connection pooling

FRONTEND:
  Framework: Tailwind CSS
  Templating: Jinja2
  Frontend Logic: Vanilla JavaScript (no dependencies)
  Data Loading: Fetch API (AJAX)
  Calculations: Client-side (real-time)

PERFORMANCE:
  ✓ Single page load - no server round-trips for calculations
  ✓ Dynamic data loaded via AJAX
  ✓ Lightweight API endpoints
  ✓ No N+1 queries
